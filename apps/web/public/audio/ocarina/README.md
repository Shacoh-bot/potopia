# Airs d’ocarina

Extraits de la bande-son de The Legend of Zelda: Ocarina of Time (Nintendo, 1998), musique de Koji Kondo.
Source : https://www.mariomayhem.com/downloads/sound_tracks/zelda_ocarina_of_time_ost.php

- zelda.mp3 : piste 25, Ocarina — Zelda’s Lullaby.
- epona.mp3 : piste 27, Ocarina — Epona’s Song.
- sun.mp3 : piste 31, Ocarina — Sun’s Song.
- saria.mp3 : piste 34, Ocarina — Saria’s Song.
- time.mp3 : piste 43, Ocarina — Song of Time.
- storms.mp3 : piste 56, Ocarina — Song of Storms.
- bolero-fire.mp3 : piste 60, Bolero of Fire.
- serenade-water.mp3 : piste 63, Serenade of Water.

Ces enregistrements remplacent les motifs synthétisés du composant. Lecture unique au clic, sans boucle.
